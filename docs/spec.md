# Спецификация: лендинг завода «Мартенсит»

Одностраничный сайт завода светопрозрачных конструкций. Источник правды по фактам — `lib/site.ts`. Этот документ фиксирует продукт, ограничения и текущее состояние. Не выдумывать факты сверх списка ниже.

## Позиционирование

Завод полного цикла СПК, не салон окон и не ритейл. Два клиента на одной странице: частный заказчик и B2B (застройщик, подрядчик). Три равные опоры:

1. Производство и монтаж на алюминии и ПВХ
2. Замер и проектирование: сложная архитектура и типовые задачи
3. Сервис действующих конструкций

Тон: деловой, конкретный. Глаголы: производим, монтируем, замеряем, проектируем, обслуживаем. Не «окна со скидкой».

## Стек

- Next.js 16 App Router, TypeScript, Tailwind v4, React 19
- Шрифт Geologica через `next/font` (кириллица + latin, ось резкости SHRP для набора) и Oswald для заголовков
- Фото через `next/image`
- Статическая генерация страниц
- Хостинг: Node. Dev: `npm run dev` → `0.0.0.0:3000`. Prod: `npm start` / PM2 → `0.0.0.0:3002`
- PM2: `npm run pm2` (сборка, затем `ecosystem.config.cjs`, процесс `martensit`)

Домен ещё не задан. Canonical и JSON-LD берут `NEXT_PUBLIC_SITE_URL`, иначе `http://localhost:3000`.

## Структура лендинга

1. **Шапка** — бренд, якоря (Производство, Проектирование, Сервис, Объекты, Контакты), телефон, переключатель темы, Telegram.
2. **Hero** — тёмный экран с отдельным тёмным чертежом фасада (русский ГОСТ-лист, не тот же файл, что у светлых секций): текст, CTA «Новый объект / заказать замер» и «Сервис действующей конструкции», внизу того же фона — мощность 2 500–3 000 м² в месяц, без соседних выдуманных KPI.
3. **Полный цикл** — три карточки опор.
4. **Системы** — алюминий и ПВХ, без каталога SKU. Карточки с иллюстрациями.
5. **Поставщики** — статический ряд логотипов без подложки: алюминий — Алютех, Алнео, Татпроф, Проведал; ПВХ — ТиСН (58 / 70 мм), Экспроф, KBE (подпись «от 100 000»). Кнопка «Подробнее о поставщиках» и логотипы ведут на `/postavshchiki`. Другие бренды рам не добавляем.
6. **Проектирование** — сложная архитектура и типовые задачи.
7. **Сервис** — диагностика, ремонт, обслуживание действующих конструкций. CTA «Вызвать сервис». Справа иллюстрация узла обслуживания (`public/illustrations/service.jpg`), не фото из портфолио.
8. **Кому** — две карточки: частник и застройщик/подрядчик, без общего заголовка.
9. **Остекление под ключ** — два маршрута (новый объект / сервис), старт через заявку, звонок, почту или Telegram.
10. **Объекты** — горизонтальная галерея всех 20 сгенерированных кадров со snap-прокруткой, стрелками и счётчиком. Кадры подобраны под подписи. Адреса объектов не указываем.
11. **FAQ** — география, замер, мощность, типовые окна, сервис.
12. **Контакты** — бренд, город, телефон, почта, Telegram и форма заявки с капчей и необязательным файлом (фото, PDF, ZIP, DWG/DXF, до 10 МБ). Без адреса и карты.
13. **Подвал** — бренд, город, покрытие, навигация, поставщики, карта сайта, реквизиты, политика. Без телефона, почты и мессенджеров.

Якоря: `#proizvodstvo`, `#proektirovanie`, `#servis`, `#obekty`, `#kontakty`.

## Тема оформления

- Режимы: `light` (по умолчанию) → `dark` → `system` (цикл кнопкой в шапке).
- Первый заход: светлая тема, без вспышки (inline-скрипт в `app/layout.tsx`).
- Выбор пишется в `localStorage` (`martensit-theme`).
- CSS-токены в `app/globals.css` через `data-theme`.
- Hero остаётся тёмным в обеих темах.

Фирменный стиль с официального lockup, визуально ближе к промышленному корпоративному сайту (ориентир: kzgroup.ru), без копирования их красно-жёлтого бренда:

- Знак: геометрическая циан-бабочка, `public/brand/mark.png` (прозрачный фон). На светлой и тёмной теме один и тот же знак.
- Слово «Мартенсит» наборное (Oswald, капитель), не PNG-wordmark.
- Тело текста: Geologica.
- Полный lockup: `public/brand/lockup.png` — для JSON-LD и светлого фона.
- Цвета: стальной фон `#E6E7E9`, уголь `#141414`, акцент/CTA `#74C4CD`, ссылки на светлом `#18747E`.
- Углы UI прямые (`rounded-none`): панели и кнопки как заводские плиты, без «таблеток».
- Секции: кикер капителью, крупные рубленые H2, тёмная плашка мощности.

Визуальный тон: уголь, сталь, циан и геометрия, не красно-белый ритейл.
