# Спецификация: лендинг завода «Мартенсит»

Одностраничный сайт завода светопрозрачных конструкций. Источник правды по фактам — `lib/site.ts`. Этот документ фиксирует продукт, ограничения и текущее состояние. Не выдумывать факты сверх списка ниже.

## Позиционирование

Завод полного цикла СПК, не салон окон и не ритейл. Два клиента на одной странице: частный заказчик и B2B (застройщик, подрядчик). Три равные опоры:

1. Производство и монтаж на алюминии и ПВХ
2. Замер и проектирование: сложная архитектура и типовые задачи
3. Сервис действующих конструкций

Тон: деловой, конкретный. Глаголы: производим, монтируем, замеряем, проектируем, обслуживаем. Не «окна со скидкой».

## Стек

- Next.js 16 App Router, TypeScript, Tailwind v4, React 19
- Шрифт Geologica через `next/font` (кириллица + latin, ось резкости SHRP для заголовков)
- Фото через `next/image`
- Статическая генерация страниц
- Хостинг: Node. Dev: `npm run dev` → `0.0.0.0:3000`. Prod: `npm start` / PM2 → `0.0.0.0:3002`
- PM2: `npm run pm2` (сборка, затем `ecosystem.config.cjs`, процесс `martensit`)

Домен ещё не задан. Canonical и JSON-LD берут `NEXT_PUBLIC_SITE_URL`, иначе `http://localhost:3000`.

## Структура лендинга

1. **Шапка** — бренд, якоря (Производство, Проектирование, Сервис, Объекты, Контакты), телефон, переключатель темы, Telegram.
2. **Hero** — коллаж из 22 уникальных фото, медленный зацикленный сдвиг влево. Текст поверх тёмной шторки (герой всегда тёмный, чтобы читался на фото). Бейдж мощности, CTA «Новый объект / заказать замер» и «Сервис действующей конструкции».
3. **Мощность** — одна цифра 2 500–3 000 м² в месяц, без соседних выдуманных KPI.
4. **Полный цикл** — три карточки опор.
5. **Системы** — алюминий и ПВХ, без каталога SKU и без чужих брендов рам.
6. **Проектирование** — сложная архитектура и типовые задачи.
7. **Сервис** — диагностика, ремонт, обслуживание действующих конструкций. CTA «Вызвать сервис».
8. **Кому** — две карточки: частник и застройщик/подрядчик, без общего заголовка.
9. **Остекление под ключ** — два маршрута (новый объект / сервис), старт через заявку, звонок, почту или Telegram.
10. **Объекты** — сетка всех 22 фото. Адреса объектов не указываем.
11. **FAQ** — география, замер, мощность, типовые окна, сервис.
12. **Контакты** — бренд, город, телефон, почта, Telegram и форма заявки с капчей (картинка на своём сервере, `/api/captcha`). Без адреса и карты.
13. **Подвал** — бренд, город, покрытие, навигация, политика. Без телефона, почты и мессенджеров.

Якоря: `#proizvodstvo`, `#proektirovanie`, `#servis`, `#obekty`, `#kontakty`.

## Тема оформления

- Режимы: `system` (по умолчанию) → `light` → `dark` (цикл кнопкой в шапке).
- Первый заход: `prefers-color-scheme`, без вспышки (inline-скрипт в `app/layout.tsx`).
- Выбор пишется в `localStorage` (`martensit-theme`).
- CSS-токены в `app/globals.css` через `data-theme`.
- Hero остаётся тёмным в обеих темах.

Фирменный стиль с официального lockup:

- Знак: геометрическая циан-бабочка, `public/brand/mark.png` (прозрачный фон). На светлой и тёмной теме один и тот же знак.
- Слово «Мартенсит» наборное (Geologica, капитель), не PNG-wordmark: на тёмном фоне чёрные буквы с lockup не читаются.
- Полный lockup: `public/brand/lockup.png` — для JSON-LD и светлого фона.
- Цвета: фон `#ECEBE9`, уголь `#1B1A1B`, акцент/CTA `#74C4CD`, ссылки на светлом `#18747E`.
- Углы UI ближе к знаку: `rounded-md` / `rounded-xl`, без «таблеток».

Визуальный тон: уголь, циан и геометрия, не красно-белый ритейл.

## SEO

- JSON-LD: `LocalBusiness` + `Manufacturer`, `areaServed` Россия и Воронеж, без `streetAddress` и `geo`. `sameAs`: Telegram. FAQ синхронизирован со страницей.
- Один H1. Секции — H2.
- Яндекс.Метрика: счётчик `111903056`. Коды верификации Вебмастера / Search Console — когда заказчик даст.
